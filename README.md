# مساعد واتساب الذكي — Gemini Flash MVP

**المطوّر:** خضر أبو صالحه (khader abo salha) — mankhader@gmail.com

مشروع Android/Kotlin عربي، يتضمن إعداد مفتاح Gemini API من داخل التطبيق واختباره ثم حفظه مشفراً باستخدام Android Keystore.

## الجديد في هذه النسخة
- ثلاثة مظاهر مستوحاة من الصور المرفقة: **زمردي** (طبقات خضراء على الأسود)، **فيروزي** (ورقة مطوية على الأسود)، **ذهبي** (ورقة ذهبية على الأزرق). تُغيَّر من قسم «المظهر» وتُحفظ، وتنعكس ألوانها على الأيقونة العائمة.
- واجهة جديدة بالكامل: بطاقات زجاجية، اتجاه RTL، شاشة بحافة كاملة، وقسم «الجاهزية» يعرض حالة كل صلاحية مع زر لمنحها.
- قسم «محادثة تجريبية»: محادثة وهمية داخل التطبيق تلعب فيها دور جهة الاتصال ويرد المساعد بنفس أسلوبه الحقيقي (مع ذاكرة للمحادثة، ويعمل حتى بدون مفتاح Gemini بالردود الجاهزة).
- أيقونة تطبيق جديدة، وسطر حقوق المطوّر أسفل الشاشة (البريد قابل للنقر).

## الأخطاء التي أُصلحت
- ملف جهة الاتصال (العلاقة والأسلوب) لم يكن يُحمَّل عند فتح التطبيق، فكان الحفظ يمسح البيانات القديمة.
- `maxOutputTokens=220` قد يستهلكها تفكير Gemini 3.x فيعود الرد فارغاً؛ رُفع الحد إلى 2048، مع تجاهل أجزاء التفكير، ونموذج احتياطي `gemini-flash-latest` عند خطأ 404.
- نص الرسالة الواردة صار يُعامل كبيانات فقط (حماية من حقن التعليمات)، وتعليمات النظام تُرسل في `systemInstruction`.
- طلب إذن `POST_NOTIFICATIONS` وقت التشغيل (أندرويد 13+) وإلا لا تظهر إشعارات الموافقة.
- الأيقونة العائمة: كان حجمها 58 بكسل (صغيرة جداً)، وكانت تنهار إن لم يُمنح إذن الظهور فوق التطبيقات؛ أُصلح الحجم بوحدة dp والتحقق من الإذن، وأُضيف زر إيقافها.
- المستمع: منع تكرار الرد على إشعار يُعاد نشره، تجاهل إشعارات التجميع، مطابقة الأسماء بلا حساس لحالة الأحرف، والرجوع لإشعار الموافقة إن فشل الإرسال التلقائي بدل ضياع الرد.
- إشعار الموافقة: PendingIntent صار `IMMUTABLE`، يُغلق الإشعار بعد الإرسال، وأيقونة الزر لم تعد تعتمد على حقل قديم.
- حذف جهة الاتصال يحذف ملفها وردودها أيضاً.
- `allowBackup=false` حتى لا تُستعاد البيانات المشفرة على جهاز آخر فيتعذر فك تشفيرها.
- سمة نظام داكنة بدل الفاتحة (كان شريط الحالة أبيض فوق واجهة داكنة).

## ميزات النسخة
- إعداد Gemini Flash باستخدام مفتاح API يدخله المستخدم.
- زر «فحص وحفظ المفتاح»: يرسل اختباراً سريعاً للنموذج، ويحفظ المفتاح فقط إذا نجح الاتصال.
- حذف المفتاح المحفوظ.
- حفظ المفتاح محلياً بتشفير AES-GCM، والمفتاح المشفّر نفسه محفوظ في Android SharedPreferences.
- توليد رد عربي مناسب من الرسالة الواردة مع ملف العلاقة والردود المخصصة.
- تنقيح الرد قبل عرضه/إرساله.
- القائمة البيضاء لجهات الاتصال، وضع الموافقة أو التلقائي، الأيقونة العائمة، والإشعارات.
- GitHub Actions workflow يبني Debug APK ويرفعه كـ Artifact عند Push أو Pull Request أو تشغيل يدوي.

## إعداد Gemini API Key
1. أنشئ مفتاحاً من Google AI Studio: https://aistudio.google.com/app/apikey
2. افتح التطبيق، الصق المفتاح في قسم Gemini Flash.
3. اضغط «فحص وحفظ المفتاح».
4. عند نجاح الاختبار سيُحفظ المفتاح مشفراً على الجهاز. لا يظهر المفتاح بعد الحفظ.

**مهم:** ليس كل مفتاح Google صالحاً تلقائياً. يجب أن يكون مفتاح Gemini Developer API صالحاً، ومفعّلاً للمشروع/النموذج `gemini-3.8-flash`، وأن تتوفر حصة استخدام. المستوى المجاني متاح وفق أهلية وحصص Google المتغيرة، وليس هناك مفتاح مجاني عام مشترك.

## بناء المشروع على GitHub
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع (وليس الملف ZIP نفسه فقط).
3. افتح تبويب **Actions**؛ سيعمل workflow المرفق تلقائياً.
4. بعد نجاح البناء افتح تشغيل workflow ثم **Artifacts** وحمّل `SmartWhatsAppAssistant-debug` للحصول على APK.

الـ workflow يستخدم Java 17 وGradle 8.11.1 و`gradle assembleDebug`.

## بناء محلياً
افتح المجلد في Android Studio حديث، ثم Sync Gradle وشغّل `app` على جهاز Android 8 أو أحدث.

## صلاحيات أندرويد
- Notification access لقراءة معاينة إشعارات واتساب.
- Display over other apps للأيقونة العائمة.
- Internet للاتصال بـ Gemini.

## ملاحظات الأمان والحدود
- استخدم وضع «طلب الموافقة قبل الإرسال» أثناء التجربة. الإرسال التلقائي قد يرسل رداً غير مناسب إذا فهم النموذج الرسالة خطأ.
- مفتاح API مشفر أثناء التخزين المحلي، لكنه يُستخدم من التطبيق على الجهاز؛ لا تنشر مفاتيحك في GitHub أو السجلات أو لقطات الشاشة. للتطبيق التجاري متعدد المستخدمين الأفضل استخدام خادم وسيط مع حصص وحماية.
- نموذج Gemini يعالج نص الرسالة وملف العلاقة والردود الجاهزة عبر الإنترنت؛ لا ترسل معلومات حساسة إلا إذا كنت موافقاً على سياسة Google.
- استقبال الرسائل يعتمد على إشعارات واتساب، وقد لا تظهر كل الرسائل أو أسماء جهات الاتصال بالشكل نفسه على جميع الأجهزة.
- الإرسال يعتمد على وجود إجراء الرد السريع `RemoteInput` في إشعار واتساب. لا يمكن ضمانه في كل إصدار/جهاز؛ عند غيابه لن يتم الإرسال.
- هذا مشروع MVP غير مختبر على جميع الأجهزة. لم يتم إنشاء APK جاهز هنا؛ GitHub Actions يبنيه عند رفعه للمستودع.
